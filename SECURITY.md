# Security

Please report vulnerabilities privately. Do not open a public issue for an
exploitable defect in the sandbox, approvals, or secret handling.

## Report

Use [GitHub Security Advisories](https://github.com/Vignesh-Rajarajan/golum/security/advisories/new)
for this repository.

Include:

- the affected version (tag or commit)
- a reproduction that stays inside a throwaway workspace
- the impact (path escape, secret leak, unexpected tool execution)

## Response

The maintainer will acknowledge the report and coordinate a fix and disclosure.
Public discussion happens after a release or when the report is not a
vulnerability.
